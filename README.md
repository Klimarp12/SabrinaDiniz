# ⚖️ Sabrina Diniz Advocacia | Landing Page

Site institucional de alto padrão desenvolvido para o escritório de advocacia da Dra. Sabrina Diniz. O projeto foi estruturado para transmitir excelência, precisão técnica e um olhar humanizado, refletindo o modelo de atuação do escritório em São José do Rio Preto (SP) e de forma remota para todo o Brasil.

## 🎨 Conceito Visual (Design System)
O design da página foi idealizado com base em interfaces modernas (inspirado no ecossistema Apple), garantindo uma experiência premium ao usuário através de:
* **Minimalismo:** Amplo uso de espaços em branco (respiro) e paleta de cores sóbria.
* **Glassmorphism:** Efeito de vidro fosco (jateado) aplicado ao menu de navegação e aos cards de áreas de atuação.
* **Tipografia e Acabamento:** Foco total em legibilidade, contraste sutil e cantos arredondados fluidos.

## 🚀 Funcionalidades
* **Design 100% Responsivo:** Experiência adaptada e fluida para smartphones, tablets e desktops.
* **Navegação Suave (Smooth Scroll):** Âncoras que guiam o usuário de forma elegante entre as seções.
* **Integração Rápida:** Botão flutuante estilizado e CTA final conectados diretamente à API do WhatsApp para maximizar a conversão de clientes.
* **Estrutura "Single Page":** Todas as informações essenciais (Perfil, Atuação, Contato) centralizadas em uma única tela de fácil rolagem.

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação semântica de ponta a ponta.
* **CSS3:** Estilização pura utilizando CSS Variables (Custom Properties), Flexbox, CSS Grid e propriedades avançadas visuais (`backdrop-filter` para o blur do vidro). Sem dependência de frameworks externos.
